第二周学习总结：Ubuntu 操作系统基础与环境搭建
本周的学习核心主要围绕 Ubuntu 操作系统的基础理论展开，并在此基础上成功完成了 Ubuntu 24.04.1 系统的独立安装与初步配置。

在理论学习过程中，我深入了解了 Ubuntu 作为主流 Linux 发行版的开源、稳定与高效等核心特点，以及它在现代机器人开发与人工智能领域中不可替代的通用地位。通过学习，我逐步掌握了 Linux 系统的基本架构，重点理解了“一切皆文件”的设计哲学。我梳理了 Linux 的文件系统层级结构（FHS），明确了根目录（/）、系统配置目录（/etc）、用户主目录（/home）以及外部设备挂载点（/media或/mnt）的各自职能。同时，我也初步接触了 Linux 的多用户权限管理机制，理解了普通用户与超级用户（root）的区别，并认识到安全使用管理员特权的重要性。此外，通过阅读相关资料，我深刻认识到 Ubuntu 是目前主流机器人开发平台（如 ROS 1/ROS 2、MoveIt、Gazebo 仿真环境等）赖以运行的核心底座，学好 Ubuntu 是后续走向机器人底层驱动开发与算法实现的必经之路。

在工程实践方面，我亲自动手完成了 Ubuntu 24.04.1 系统的安装流程。在安装过程中，我熟悉了磁盘分区、挂载点设置、系统时区选择、用户账户创建以及系统初始化配置等一系列关键步骤。安装完成后，我对全新的系统桌面环境进行了探索，并迅速将学习重心转移到了核心交互工具——终端（Terminal）的使用上。为了摆脱对图形化界面的依赖，我集中练习并掌握了一系列高频使用的 Linux 基础 Shell 命令，并理解了它们在实际文件管理中的应用场景：

pwd（Print Working Directory）：用于在复杂的目录结构中精准查看当前所处的工作绝对路径，防止误操作。

ls（List）：用于查看当前或指定目录下的内容，并学习了 ls -l（查看详细属性与权限）和 ls -a（查看隐藏文件）等常用参数组合。

cd（Change Directory）：用于在不同层级的文件夹之间进行快速切换，熟悉了绝对路径切换、相对路径切换以及快捷返回家目录（cd ~）的操作。

mkdir（Make Directory）：用于创建新的文件夹，并尝试了使用 -p 参数递归创建多级子目录。

cp 与 mv（Copy / Move）：掌握了文件的复制、移动与重命名技巧，并深刻体会到 Linux 中移动文件与重命名在底层逻辑上的统一性。

sudo（Superuser Do）：理解了其作为提权工具的作用，能够安全地以管理员身份执行敏感的系统级命令。

此外，我还深入学习了 Ubuntu 的软件源更新与软件包管理机制，重点掌握了 APT（Advanced Package Tool）工具链的使用方法。通过实际操作 sudo apt update 和 sudo apt upgrade，我熟悉了系统软件源列表的刷新与核心依赖包的升级流程，并掌握了如何使用 sudo apt install 独立安装开发所需的工具软件。这不仅为后续顺利安装、编译机器人操作系统（ROS）及其他第三方开源库奠定了坚实的软件环境基础。

总结来说，本周的学习与实践是一次从 Windows 思维向 Linux 开发思维的重要转变。我不仅顺利完成了个人机器人开发操作系统的环境搭建，也初步建立了命令行交互的良好习惯。这层基石的打牢，为我后续深入学习机器人操作系统（ROS）架构、多传感器数据融合、机器人控制与自主导航仿真等核心内容做好了充分的准备。
