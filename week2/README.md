第二周学习总结

本周主要学习了 Ubuntu 操作系统的基础知识，并成功完成了 Ubuntu 24.04.1 系统的安装与初步配置。

在学习过程中，我了解了 Ubuntu 作为 Linux 发行版的特点，以及其在机器人开发领域中的广泛应用。通过学习，我掌握了 Linux 系统的基本结构，包括文件系统层级、用户与权限管理、软件包管理等基础概念。同时，我认识到 Ubuntu 是许多机器人开发平台和工具（如 ROS）运行的重要基础环境。

在实践方面，我完成了 Ubuntu 24.04.1 的安装，熟悉了系统安装流程，包括磁盘分区、用户创建和系统初始化配置等步骤。安装完成后，我对桌面环境进行了简单探索，学习了终端（Terminal）的基本使用方法，并尝试执行常用 Linux 命令，例如：

pwd：查看当前工作目录
ls：查看目录内容
cd：切换目录
mkdir：创建文件夹
cp、mv：复制和移动文件
sudo：以管理员权限执行命令

此外，我还学习了 Ubuntu 软件更新与软件安装的方法，了解了 APT 软件包管理工具的基本使用方式，为后续安装机器人开发相关软件奠定了基础。

通过本周的学习，我不仅完成了 Ubuntu 系统环境的搭建，也初步建立了 Linux 操作系统的使用习惯，为后续学习机器人操作系统（ROS）、机器人控制与仿真等内容做好了准备。
