一、Docker 概念与基础使用

这部分主要帮助大家理解“容器化”的思想，并掌握基本操作：

了解 Docker 的核心概念：镜像（Image）、容器（Container）、仓库（Repository）
理解容器与虚拟机的区别，以及 Docker 的轻量级优势
学习 Docker 的基本工作流程：
拉取镜像 → 创建容器 → 运行应用 → 管理容器
掌握常用 Docker 命令，例如：
docker pull（拉取镜像）
docker run（运行容器）
docker ps（查看容器）
docker stop / rm（停止与删除容器）
通过实际操作体验如何用 Docker 快速部署开发环境
二、OpenCV 介绍与安装实验

这一部分主要是进入计算机视觉基础工具的学习：

了解 OpenCV 的作用：一个用于图像处理与计算机视觉的开源库
学习 OpenCV 的基本应用场景，例如：
图像读取与显示
图像处理（灰度化、滤波等）
简单的视频捕获与处理
认识 OpenCV 常见开发环境（Python / C++）
完成 OpenCV 的安装实验：
使用 pip 或环境配置安装 OpenCV
验证安装是否成功（如读取图片并显示）
运行简单示例代码，体验图像处理流程
三、课堂整体收获
初步掌握了 Docker 的容器化思想与基本操作方法
搭建了 OpenCV 的开发环境
完成了从环境部署到简单图像处理的实践流程
为后续机器学习或计算机视觉课程打下基础
