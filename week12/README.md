本实验基于 PyBullet 物理仿真平台，构建了一个四足机器人控制系统，实现了机器人自动行走与周期性空翻动作控制。

一、实验目标
实现四足机器人基础步态控制（trot gait）
实现机器人自动空翻动作
使用状态机控制复杂动作流程
使用时间控制实现自动循环行为
二、系统组成

本系统主要由以下三个部分组成：

1️⃣ 步态控制系统

机器人四条腿通过关节角度控制实现周期性运动。

使用固定关节角度模拟 trot 步态
左右腿交替运动（对角步态）
通过 POSITION_CONTROL 控制关节

👉 本质是用周期函数模拟行走，而非真实动力学控制。

2️⃣ 空翻动作控制（状态机）

空翻动作采用有限状态机（FSM）设计，包括以下阶段：

CROUCH（下蹲蓄力）
LAUNCH（起跳）
ROTATE（空中翻转）
LAND（落地）
SETTLE（稳定恢复）

👉 通过 resetBaseVelocity 施加瞬时速度，使机器人产生翻滚动作。

3️⃣ 时间控制系统

系统使用时间触发机制控制动作执行：

初始阶段：机器人先稳定站立 5 秒
运行阶段：每 10 秒自动执行一次空翻
使用时间差控制动作触发
三、核心技术原理
1. Finite State Machine（有限状态机）

用于控制复杂动作拆解，使机器人按阶段执行动作流程。

2. 时间驱动控制（Time-based Control）

通过时间间隔控制行为触发，实现自动循环动作。

3. 角动量原理

在空翻过程中通过施加角速度实现旋转运动。

4. 惯性矩变化

机器人在空中收腿可减少转动惯量，从而加快旋转速度。

四、运行流程

系统运行流程如下：

0–5 秒：机器人初始化并稳定站立
5 秒后：进入正常步态运行
每 10 秒：触发一次空翻动作
空翻完成后恢复站立并继续运行
五、实验结果

最终实现效果如下：

四足机器人可稳定站立与行走
能自动执行周期性空翻动作
动作过程包含完整的起跳、旋转与落地阶段
系统可持续运行，无需人工干预
六、总结

本实验通过 PyBullet 仿真环境实现了四足机器人的基础运动控制与复杂动作设计。系统采用状态机与时间控制方法，实现了自动行走与周期性空翻功能，为后续机器人强化学习与动态控制研究奠定基础。
