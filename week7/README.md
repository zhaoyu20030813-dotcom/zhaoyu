本周学习总结

本周主要围绕 Linux 与开发环境复习、Markdown 文档编写以及 GitHub 期中作业整理展开，具体内容如下：

一、复习内容

本周对前期所学内容进行了系统复习，主要包括：

Linux 基础命令的使用（文件管理、路径操作等）
Ubuntu 系统的基本操作与环境使用
Docker 基础概念及常用命令（如 run、ps、images、commit 等）
WSL（Windows Subsystem for Linux）环境的使用与切换

通过本次复习，进一步巩固了 Linux 系统操作及容器化环境的基本使用方法，提高了对开发环境整体结构的理解。

二、Markdown 学习

本周重点学习了 Markdown 的基本语法与文档编写方法，包括：

标题结构（#、##、###）
无序列表与有序列表
代码块的使用（如 bash 等格式）
超链接与图片插入方法
文档整体结构与排版规范

同时尝试使用 Markdown 对学习内容进行整理，使文档结构更加清晰、规范，提高了学习记录的可读性与条理性。

三、期中作业（GitHub 项目整理）

本次期中考试以作业形式完成，主要任务为对 GitHub 仓库进行整理与规范化管理。

完成内容如下：

对 GitHub 仓库目录结构进行重新整理
按功能模块分类文件（代码 / 文档 / 作业 / 实验）
添加 README.md 文件，对项目内容进行说明
使用 Markdown 优化文档排版结构
提升仓库整体的可读性与规范性

通过本次整理，不仅提高了代码与文档的组织能力，也增强了对 GitHub 项目管理规范的理解。

四、本周总结

总体来看，本周通过“知识复习 + 文档学习 + 项目整理”的方式，进一步巩固了 Linux 与开发环境相关基础知识，同时提升了 Markdown 文档编写能力与 GitHub 项目管理能力，为后续更复杂的开发与机器人项目实践打下基础。
