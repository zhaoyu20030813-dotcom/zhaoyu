本周在解决什么问题？

机器人视觉的基础问题：

目标在画面中的“位置 + 距离”如何获得？

所以课程不是单纯玩摄像头，而是搭一个完整视觉系统：

输入：手机摄像头
传输：网络（Tailscale）
处理：WSL + Python + OpenCV
目标：ArUco识别 + 位姿/距离估计
2️⃣ 整体系统结构（最重要）

你最终搭出来的是这条链路：

手机摄像头
   ↓
HTML5 浏览器采集
   ↓
Tailscale 虚拟网络
   ↓
WSL Ubuntu（Flask 摄像头桥接）
   ↓
OpenCV
   ↓
ArUco 检测（+ 后续标定测距）
3️⃣ 为什么要这样设计？
📱 用手机
零成本
接近真实机器人摄像头
可远程部署
🌐 用 Tailscale

解决两个现实问题：

校园网设备隔离（手机访问不到电脑）
WSL2 NAT 隔离（外部访问不到 WSL）

👉 本质：把手机和 WSL 放进同一个虚拟局域网

4️⃣ WSL 中你做了什么？
✔ 安装网络能力
Tailscale → 让设备互通
SSH → 验证“网络不仅能传视频，还能远程登录”
✔ 启动服务
camera_bridge.py (Flask HTTPS 服务)

作用：

接收手机浏览器上传的实时视频帧

✔ 安装依赖
pip install flask opencv-python numpy ...
